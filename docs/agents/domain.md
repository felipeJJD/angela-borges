# Domain docs

This repository uses a single-context domain layout.

## Before exploring

- Read `CONTEXT.md` at the repository root when it exists.
- Read relevant ADRs under `docs/adr/` when they exist.
- If either path is absent, proceed silently; domain-modeling creates them only when terminology or decisions need durable documentation.

## Vocabulary

Use the terms defined in `CONTEXT.md` in issue titles, tests, specifications, and implementation notes. If a needed concept is missing, reconsider whether it is a synonym or record the gap for domain-modeling.

## ADR conflicts

Surface conflicts with an existing ADR explicitly instead of silently overriding the decision.
